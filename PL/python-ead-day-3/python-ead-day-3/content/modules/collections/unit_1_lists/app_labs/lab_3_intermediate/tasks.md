# Lab 3 Tasks: Doctor-Specific Filtering

## Task 1: Comprehensive Filtering
**Difficulty**: Intermediate | **Points**: 100

### Objective
Extract relevant records.

### Requirements
- Given a `master_schedule` list of dictionaries.
- Each dictionary has `patient`, `doctor`, and `time`.
- Create a new list `dr_smith_list` using a list comprehension.
- Only include records where `doctor` is "Smith".
