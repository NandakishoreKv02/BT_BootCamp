# Lab 4 Tasks: Chronological Sort

## Task 1: Basic String Sort
**Difficulty**: Intermediate | **Points**: 100

### Objective
Order time-based data.

### Requirements
- Given a list `appointment_times = ["14:00", "09:30", "11:00", "08:15"]`.
- Sort the list in place using `.sort()`.
- Create a copy of the sorted list and reverse it using `.reverse()`, storing it in `reverse_times`.
