# Lab 2 Tasks: Dynamic Slot Management

## Task 1: Insert and Serve
**Difficulty**: Easy | **Points**: 100

### Objective
Modify list order.

### Requirements
- Start with a list `slots = ["Patient A", "Patient B"]`.
- Insert "EMERGENCY" at the beginning (index 0).
- Remove "Patient A" from the list (cancellation).
- Use `pop(0)` to remove and return the first person in line, storing them in a variable `current_patient`.
