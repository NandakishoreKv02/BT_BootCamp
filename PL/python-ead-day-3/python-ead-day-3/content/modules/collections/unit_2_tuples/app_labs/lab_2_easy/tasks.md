# Lab 2 Tasks: Tuple Unpacking & Swapping

## Task 1: Unpack Vitals
**Difficulty**: Easy | **Points**: 100

### Objective
Distribute data to variables.

### Requirements
- Given `vitals_data = (38.2, 85, 120)`.
- Unpack these into `temperature`, `heart_rate`, and `systolic_bp`.
- Assume two doctors, `doc_a = "Dr. Smith"` and `doc_b = "Dr. Jones"`, need to swap their assigned rooms. Use tuple swapping to exchange their values.
