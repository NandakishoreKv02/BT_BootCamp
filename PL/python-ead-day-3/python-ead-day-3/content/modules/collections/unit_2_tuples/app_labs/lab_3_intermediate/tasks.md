# Lab 3 Tasks: Self-Documenting Records

## Task 1: Create a NamedTuple
**Difficulty**: Intermediate | **Points**: 100

### Objective
Apply structure to immutable data.

### Requirements
- Import `namedtuple` from the `collections` module.
- Define a `NamedTuple` named `LabResult` with fields: `test_name`, `value`, `unit`.
- Create an instance `glucose_test` with values: `"Glucose"`, `95`, `"mg/dL"`.
- Access and print `glucose_test.test_name`.
