# Lab 1 Tasks

## Task 1: Define the Blueprint
Create a class named `Patient`. Use the correct casing.

## Task 2: Implement the Constructor
Add a `def __init__(self, patient_id, full_name):` method.
Inside, assign the arguments to `self.patient_id` and `self.full_name`.

## Task 3: Create and Verify
In the `main()` function:
1. Instantiate a patient: `p1 = Patient("P-100", "John Doe")`.
2. Print a confirmation message using the object's attributes.
