# Lab 1 Tasks

## Task 1: Define PatientState
Create a class `PatientState`.
- `__init__(self, pid, hr, temp)`: Store these as instance attributes.

## Task 2: Create Instances
In `main()`:
1. Create `p1` (ID: 101, HR: 72, Temp: 98.6).
2. Create `p2` (ID: 102, HR: 85, Temp: 99.1).

## Task 3: Test Independence
- Print the heart rates of both.
- Modify `p1.hr = 100`.
- Print both again to show that `p2.hr` remains 85.
