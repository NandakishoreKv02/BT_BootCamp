# Lab 2 Tasks

## Task 1: Define Admission
Create a class `Admission`.
- Outside any methods, define `total_patients = 0`.
- In `__init__(self, name)`:
  - Set `self.name`.
  - Increment `Admission.total_patients` by 1.

## Task 2: Create a Crowd
In `main()`:
1. Create 3 different `Admission` objects.
2. Print the value of `Admission.total_patients`.
3. Create 2 more `Admission` objects.
4. Print the value of `Admission.total_patients` again to show it grew.
