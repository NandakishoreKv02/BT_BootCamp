# Lab 1 Tasks

## Task 1: Static Variable Definition
- Define the `BedAdmission` class.
- Create a variable `occupied_beds` outside the `__init__` method and set it to 0.

## Task 2: Increment Logic
- In the `__init__` constructor:
  - Increment the class variable using the class name: `BedAdmission.occupied_beds += 1`.

## Task 3: Reporting
In `main()`:
1. Print "Admitting Patient X..." three times.
2. In each print, create a new `BedAdmission()` instance.
3. Finally, print the class-level count.
