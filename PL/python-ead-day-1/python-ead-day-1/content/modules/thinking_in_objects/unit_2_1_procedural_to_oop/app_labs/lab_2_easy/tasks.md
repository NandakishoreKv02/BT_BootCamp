# Lab 2 Tasks

## Task 1: The Constructor
Create `create_lab_result(pid, test_name, value)`:
- Returns `{'pid': ..., 'test': ..., 'value': ...}`.

## Task 2: Data Migration
The starter code has raw lists.
Create a new list `results = []`.
Populate it using the `create_lab_result` function for each entry in the raw lists.

## Task 3: Reporting
Create `print_lab_report(results_list)`:
- Loops through the list of dictionaries.
- Prints the formatted details.

## Task 4: Upgrade
Add `update_result(result, new_value)`:
- Takes a SINGLE result dictionary.
- Updates its value.
