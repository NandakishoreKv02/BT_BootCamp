# Unit 1.1: Introduction to Python - Learning Outcomes

## Overview
In this unit, you will be introduced to the Python programming language, its philosophy, and its role in modern software development. You will understand why Python has become the language of choice for healthcare systems, data science, and web development. This foundational unit sets the stage for your entire Python journey by establishing core concepts and best practices.

**Estimated Time**: 3-4 hours
- Knowledge: 60 min
- Exercises: 2-3 hours

---

## Learning Outcomes

After successfully completing this unit, you will be able to:

### Understanding Python
- [ ] **Define** what Python is and identify its key characteristics (interpreted, high-level, dynamically typed).
- [ ] **Explain** the history of Python and its creator, Guido van Rossum.
- [ ] **Identify** the core design principles of Python as outlined in the "Zen of Python" (PEP 20).

### Python's Ecosystem and Use Cases
- [ ] **Articulate** why Python is preferred in domains like Healthcare, AI, Web Development, and Scientific Computing.
- [ ] **Recognize** the "Batteries Included" philosophy and how it accelerates development.
- [ ] **List** at least 5 major Python libraries/frameworks and their primary use cases (e.g., Django, pandas, TensorFlow).

### Language Comparison
- [ ] **Compare** Python with other common languages (C++, Java, JavaScript) in terms of:
  - Syntax complexity and readability
  - Execution speed (interpreted vs compiled)
  - Use case suitability
- [ ] **Evaluate** when to choose Python over other languages for a given project.

### Python Versions and Compatibility
- [ ] **Understand** the significance of Python 3 over Python 2 and why Python 2 reached End of Life.
- [ ] **Verify** your Python installation version using command-line tools.
- [ ] **Explain** the importance of using Python 3.10+ for modern healthcare applications.

### Best Practices and Philosophy
- [ ] **Apply** the Zen of Python principles to evaluate code quality (e.g., "Explicit is better than implicit").
- [ ] **Recognize** common Python coding mistakes related to indentation and style.
- [ ] **Follow** PEP 8 style guidelines for writing clean, maintainable code.

## Common Pitfalls to Avoid
✅ **Do**: Always use Python 3.10+ for new projects to benefit from the latest features and security updates.
❌ **Don't**: Start learning or building projects with Python 2.x, as it is no longer supported.

✅ **Do**: Embrace Python's philosophy of readability and simplicity when writing code.
❌ **Don't**: Write overly "clever" code that sacrifices clarity for brevity.

✅ **Do**: Understand that Python's interpreted nature makes it slower than compiled languages, but this is often acceptable for the development speed it provides.
❌ **Don't**: Assume Python is the best choice for every scenario (e.g., mobile app development or real-time systems with strict performance requirements).
