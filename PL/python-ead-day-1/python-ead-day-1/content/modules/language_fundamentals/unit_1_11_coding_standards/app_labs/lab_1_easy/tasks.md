# Lab 1: The Great Variable Cleanup - Tasks

## Task 1: Meaningful Calculation
In `refactor_balance_logic`, create a variable to hold the difference between intake and output. Choose a name like `fluid_balance`.

## Task 2: Descriptive Status
Instead of `s`, use a name like `balance_status`.

## Task 3: Consistency
Ensure all logic uses your new variable names.

## Task 4: Return
The function should return a dictionary with keys `"balance"` and `"status"`.
Observe how much easier the code is to read with descriptive names!
