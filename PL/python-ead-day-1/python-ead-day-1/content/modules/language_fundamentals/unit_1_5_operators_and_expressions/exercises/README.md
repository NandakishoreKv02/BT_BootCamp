# Unit 1.5: Operators & Expressions - Exercises

## Overview
These exercises focus on applying Python's mathematical and logical operators in a clinical context.

## Instructions
1. Open `unit_1_5_operators_and_expressions_exercises.py`.
2. Complete each exercise function using the specified operators.
3. Run the file to verify your work:
   ```bash
   python unit_1_5_operators_and_expressions_exercises.py
   ```

## Exercise List

### 1. Dosage Calculation (Arithmetic)
Calculate full tablets and remaining MG using floor division (`//`) and modulus (`%`).

### 2. Range Checker (Comparison)
Check if a temperature is within a safe range using comparison operators.

### 3. Emergency Alert (Logical)
Combine multiple Boolean conditions using `and`, `or`, and `not` to decide if an alert is necessary.

### 4. Blood Type & User Check (Membership/Identity)
Use `in` to validate a string against a list and `is` to check for a `None` object.

### 5. Dosage Update (Assignment)
Update a numerical value using shorthand assignment operators like `+=` and `*=`.

### 6. Precedence Puzzle
Force a specific order of calculation using parentheses to override standard mathematical precedence.
