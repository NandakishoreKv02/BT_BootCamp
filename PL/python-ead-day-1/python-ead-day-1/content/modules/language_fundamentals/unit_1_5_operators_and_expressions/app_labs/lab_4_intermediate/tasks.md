# Lab 4: Secure Access Validator - Tasks

## Task 1: Identity Check
Check if `user_obj` is not `None` using the `is not` identity operator.

## Task 2: Membership Check
Check if `user_role` is present in the `APPROVED_ROLES` list using the `in` operator.

## Task 3: Logical Combination
Combine both checks with the `and` operator. Ensure that if `user_obj` is `None`, the membership check doesn't cause any issues (short-circuiting).
