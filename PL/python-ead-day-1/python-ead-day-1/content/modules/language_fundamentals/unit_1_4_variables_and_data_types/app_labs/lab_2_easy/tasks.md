# Lab 2: BMI Calculator - Tasks

## Task 1: Type Checking
Ensure input `weight` and `height` are floats. If they are integers, convert them.

## Task 2: Calculate BMI
Implement `weight / (height ** 2)`.

## Task 3: Handle Edge Cases
Prevent division by zero. If height <= 0, return 0.0.

## Task 4: Rounding
Use Python's `round(val, 2)` to standardise the output.
