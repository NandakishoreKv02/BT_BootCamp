# Unit 1.10: I/O & Basic Utilities - Exercises

## Overview
These exercises focus on the essential "edge" of your application: how it gets data from users and files, and how it presents results back to them in a professional, persistent way.

## Instructions
1. Open `unit_1_10_io_and_utils_exercises.py`.
2. Complete each exercise function using specific formatting and I/O methods.
3. Run the file to verify your work:
   ```bash
   python unit_1_10_io_and_utils_exercises.py
   ```

## Exercise List

### 1. Age Projection (Input/Casting)
Handle raw string input and convert it to a numeric type for calculation.

### 2. Lab Labeling (F-Strings)
Create a professional, aligned table row using padding and decimal precision codes.

### 3. Patient Note Saver (File Writing)
Use a context manager to save string data to a local `.txt` file.

### 4. History Loader (File Reading)
Safely read the first line of a file while handling the case where the file is missing.

### 5. Arg Counter (CLI Awareness)
Understand how to count parameters passed into the script from the command line.

### 6. Menu Logic (Input Cleaning)
Practice stripping and case-standardizing user input for robust menu navigation.
