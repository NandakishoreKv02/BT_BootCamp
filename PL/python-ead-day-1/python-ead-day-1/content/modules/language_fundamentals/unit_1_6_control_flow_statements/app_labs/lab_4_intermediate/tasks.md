# Lab 4: Lab Result Filter - Tasks

## Task 1: Setup
Create an empty list `cleaned`.

## Task 2: Loop with Continue
Start a `for` loop. If the current item is `None`, skip to the next iteration using `continue`.

## Task 3: Loop with Break
If the current item is the string `"CRITICAL_ERROR"`, exit the entire loop using `break`.

## Task 4: Collection
If the item passes both checks, append it to the `cleaned` list.
