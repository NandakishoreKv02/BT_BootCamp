# Lab 2: Appointment Reminder Generator - Tasks

## Task 1: Initialization
Create an empty list called `reminders`.

## Task 2: Iteration
Use a `for` loop to iterate through each name in the `patient_names` list.

## Task 3: Formatting and Collection
Inside the loop, use an f-string to create the message: `"Reminder: {name}, your appointment is at {time_str}."`
Add (append) each message to the `reminders` list.

## Task 4: Return
Return the full list of reminders.
