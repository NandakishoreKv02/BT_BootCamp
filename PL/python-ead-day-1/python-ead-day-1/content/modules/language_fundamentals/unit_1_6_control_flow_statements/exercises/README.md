# Unit 1.6: Control Flow Statements - Exercises

## Overview
These exercises focus on applying Python's decision-making and repetitive logic in a healthcare setting. You will work with triage levels, dose scheduling, and data processing.

## Instructions
1. Open `unit_1_6_control_flow_statements_exercises.py`.
2. Complete each exercise function using the specified control flow tools.
3. Run the file to verify your work:
   ```bash
   python unit_1_6_control_flow_statements_exercises.py
   ```

## Exercise List

### 1. Triage Categorization
Use `if/elif/else` to determine the triage status based on heart rate thresholds.

### 2. Dose Count Generation
Use a `for` loop and `range()` to create a schedule of even-numbered dosages.

### 3. Patient Search (Break)
Iterate through a list of names and stop immediately using `break` once a specific target is found.

### 4. Data Sanitization (Continue)
Process a list of sensor readings, skipping errors (zero or negative) using `continue`.

### 5. Monitoring Simulation (While)
Use a `while` loop to sum historical data until a "loss of signal" (zero) occurs.

### 6. Ward Triage (Nested)
Implement nested logic (loops inside conditionals) to filter and count specific patient statuses in a hospital ward.
