# Unit 1.7: Core Built-in Data Structures - Exercises

## Overview
These exercises focus on working with Python's collection types: Lists, Tuples, Sets, and Dictionaries. You will handle inventory management, patient records, and data deduplication.

## Instructions
1. Open `unit_1_7_core_built_in_data_structures_exercises.py`.
2. Complete each exercise function using the specified data structure.
3. Run the file to verify your work:
   ```bash
   python unit_1_7_core_built_in_data_structures_exercises.py
   ```

## Exercise List

### 1. Pharmacy Inventory (Lists)
Add new medications, sort the inventory, and remove discontinued items.

### 2. Patient Summary (Tuples)
Unpack a fixed-format tuple containing patient demographics.

### 3. Common Diagnoses (Sets)
Compare two hospital wards to find overlapping diagnoses using set intersection.

### 4. MRN Lookup (Dictionaries)
Find and update a specific patient's status by their Medical Record Number (MRN).

### 5. BP Extractor (Nested Data)
Navigate multiple levels of keys and indices to find a specific vital sign.

### 6. Unique Tags (Deduplication)
Transform a "dirty" list with duplicates into a clean, sorted list of unique entries.
