# Lab 3: Pediatric Multi-Dose Calculator - Tasks

## Task 1: Function Definition
Define `calculate_dosage` with parameters: `mg_per_kg`, `weight`, `daily_doses`, and `precision=2`.

## Task 2: Calculation
Calculate the total daily dose (`mg_per_kg * weight`) and then divide by the number of doses per day.

## Task 3: Return
Return the result rounded to the `precision` requested.

## Task 4: Keyword Calling (Verification)
In the `if __name__ == "__main__":` block, call your function using keyword arguments in an order *different* from the definition (e.g., `weight=10, mg_per_kg=5...`).
