# Lab 5: Patient Profile Generator - Tasks

## Task 1: Function Header
Define `create_patient_record` with the specified parameters and a default for `city`.

## Task 2: Docstring Documentation
Write a multiline string (`""" ... """`) immediately under the function header.
Include:
- A brief summary.
- List of parameters with their types.
- Description of the return value.

## Task 3: Name Formatting
Create a local variable `formatted_name` where the first and last names are converted to uppercase and joined as `"LAST, FIRST"`.

## Task 4: Dictionary Return
Return a dictionary that maps `full_name`, `age_years`, and `location` to their respective values.
