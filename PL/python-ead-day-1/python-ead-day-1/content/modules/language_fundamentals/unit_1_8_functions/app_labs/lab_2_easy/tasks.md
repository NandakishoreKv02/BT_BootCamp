# Lab 2: IV Flow Rate Calculator - Tasks

## Task 1: Function Header
Define `calculate_flow_rate` with two parameters: `volume_ml` and `time_hr`. Set `time_hr` to have a default value of `1.0`.

## Task 2: Calculation
Divide `volume_ml` by `time_hr`.

## Task 3: Value Guard
If `time_hr` is accidentally passed as 0, the function might crash. For this lab, you can assume positive inputs, but ensure you return the float result of the division.
