# Lab 1: Vital Sign Formatter - Tasks

## Task 1: Function Definition
Define a function named `format_vital` that accepts three positional parameters: `name`, `value`, and `unit`.

## Task 2: String Template
Inside the function, use an f-string to combine the parameters. The format must be: `{name}: {value} {unit}`.

## Task 3: Return
Explicity return the formatted string.
