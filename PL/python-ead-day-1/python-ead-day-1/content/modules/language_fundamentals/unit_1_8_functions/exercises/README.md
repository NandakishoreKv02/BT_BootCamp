# Unit 1.8: Functions - Exercises

## Overview
These exercises focus on building modular, reusable code snippets for common healthcare tasks like unit conversion, triage prioritization, and data formatting.

## Instructions
1. Open `unit_1_8_functions_exercises.py`.
2. Complete each exercise function using the specified logic and return statements.
3. Run the file to verify your work:
   ```bash
   python unit_1_8_functions_exercises.py
   ```

## Exercise List

### 1. Temp Conversion (Definitions)
Implement a basic math conversion function with one parameter and a return value.

### 2. Lab Urgency (Defaults)
Use default parameter values to handle optional prioritization in a formatting function.

### 3. MAP Calculation (Accuracy)
Implement a clinical clinical formula (Mean Arterial Pressure) and round the results.

### 4. Medication Logic (Keyword Arguments)
Practice calling and defining functions with descriptive parameter names.

### 5. Application Scope (Local vs Global)
Learn how to access variables from different levels of namespacing.

### 6. Drug Eligibility (Branching Returns)
Use `if/else` logic within a function to return different status strings based on input criteria.
