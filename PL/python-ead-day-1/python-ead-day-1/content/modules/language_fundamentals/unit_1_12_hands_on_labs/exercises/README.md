# Unit 1.12: Hands-on Labs & Exercises - README

## Overview
This capstone unit integrates all Python fundamentals through comprehensive, real-world healthcare applications. Each exercise combines multiple concepts you've learned throughout Module 1.

## Instructions
1. Open `unit_1_12_hands_on_exercises.py`.
2. Complete each exercise by implementing the required functionality.
3. Run the file to verify your work:
   ```bash
   python unit_1_12_hands_on_exercises.py
   ```

## Exercise List

### 1. Patient Record Builder
**Concepts**: Variables, Dictionaries, Functions  
**Task**: Create a structured patient record from individual data points.

### 2. Vital Signs Validator
**Concepts**: Control Flow, Comparison Operators, Lists  
**Task**: Identify which vital signs fall outside normal clinical ranges.

### 3. Medication List Processor
**Concepts**: Lists, Loops, Dictionaries  
**Task**: Count medications of a specific type from a complex data structure.

### 4. Lab Result Analyzer
**Concepts**: Functions, Built-in Functions (sum, min, max), Data Structures  
**Task**: Calculate comprehensive statistics for laboratory results.

### 5. Appointment Scheduler
**Concepts**: Dictionaries, Control Flow, Boolean Logic  
**Task**: Determine if a requested appointment time is available.

### 6. Patient Data File Writer
**Concepts**: File I/O, Functions, String Formatting  
**Task**: Persist patient information to a text file for record-keeping.

## Success Criteria
- All 6 exercises pass their automated tests
- Code follows PEP 8 standards
- Functions include proper docstrings
- Edge cases are handled appropriately
