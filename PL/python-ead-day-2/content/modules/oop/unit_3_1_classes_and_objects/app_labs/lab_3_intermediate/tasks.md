# Lab 3 Tasks: Instance vs Class Variables

## Task 1: Add a Class Variable
- Open `starter_code.py`.
- Inside the `Patient` class, before the `__init__` method, define a class variable `total_patients` and set it to 0.

## Task 2: Increment the Counter
- Inside the `__init__` method, increment `Patient.total_patients` by 1 every time a new instance is initialized.

## Task 3: Test the Counter
- Create three `Patient` instances with any names you like.
