# Lab 1: Defining Classes and Objects

**Module**: OOP
**Objective**: Learn how to define a basic class and create instances of it.
**Difficulty**: Easy
**Context**: Basic Patient Records

## Scenario
You are building a basic patient record system for a clinic. You need to define a `Patient` class that will act as a blueprint for all patients. For now, we will just create the class and instantiate it.

## Goals
- Define a class named `Patient`.
- Create multiple instances of the `Patient` class.

## Success Criteria
- The class `Patient` must be defined.
- Two objects `patient1` and `patient2` must be created from the `Patient` class.
