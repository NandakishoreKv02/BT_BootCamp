# Unit 3.1: Classes and Objects - Exercises

## Overview
These exercises focus on the fundamental building blocks of Object-Oriented Programming: classes, objects, constructors, and the `self` parameter. 

## Exercises Summary

### Exercise 1: Basic Class Definition & Instantiation
- **Objective**: Practice defining a minimal class and creating a concrete instance from it.
- **Skills**: `class` keyword, object instantiation.

### Exercise 2: The `__init__` Constructor
- **Objective**: Implement the standard initialization method to capture data during object creation.
- **Skills**: `__init__`, parameters.

### Exercise 3: Instance Variables and `self`
- **Objective**: Learn how to use the `self` reference to store and retrieve data unique to an instance.
- **Skills**: `self.attribute`, instance methods.

### Exercise 4: Class Variables vs Instance Variables
- **Objective**: Understand the difference between shared state (at the class level) and unique state (at the object level).
- **Skills**: Class-level attributes vs `self` attributes.

### Exercise 5: Creating Multiple Instances
- **Objective**: Scale up by creating and managing several objects programmatically using loops.
- **Skills**: List of objects, loops.

### Exercise 6: Object Identity and Equality
- **Objective**: Master the technical difference between the `is` operator (memory identity) and `==` operator (logical equality).
- **Skills**: Memory references, identity checks.

## How to Run

3. Implement the logic between the `WRITE CODE HERE` markers.
