# Unit 3.2: Methods - Exercises

## Overview
These exercises focus on the different types of methods available in Python classes: instance, class, and static methods. You will also practice handling return values and side effects correctly.

## Exercises Summary

### Exercise 1: Basic Instance Method
- **Objective**: Practice using `self` to modify object state.
- **Concepts**: `self`, state modification.

### Exercise 2: Class Method as a Factory
- **Objective**: Implement an alternative constructor using `@classmethod`.
- **Concepts**: `@classmethod`, `cls`, instantiation.

### Exercise 3: Static Method Utility
- **Objective**: Create a pure utility method inside a class.
- **Concepts**: `@staticmethod`, independent logic.

### Exercise 4: Method with Default Arguments
- **Objective**: Simulate method overloading using default parameter values.
- **Concepts**: Default arguments, optional parameters.

### Exercise 5: Return Values vs Side Effects
- **Objective**: Differentiate between actions that change state and actions that return data.
- **Concepts**: `return`, `None`, list modification.

### Exercise 6: Class-Level Coordination via `cls`
- **Objective**: Interact with shared class-level variables.
- **Concepts**: Class variables, `cls` access.

## How to Run
1. Navigate to the `exercises/` directory.
2. Open `unit_3_2_methods_exercises.py`.
3. Implement the logic between the `WRITE CODE HERE` markers.
4. Run the file: `python unit_3_2_methods_exercises.py`.
5. If all tests pass, you will see "All exercises passed!".
