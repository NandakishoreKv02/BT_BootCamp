# Lab 4: Patient Records - Access Control

**Objective**: Master public, protected, and private access levels
**Difficulty**: Intermediate

## Use Case
Implement proper access control for patient data with different sensitivity levels.

## Task Summary
- **Task 1**: Public attributes (name, age)
- **Task 2**: Protected attributes (_medical_history)
- **Task 3**: Private attributes (__ssn, __insurance_id)
- **Task 4**: Mixed access property patterns
- **Task 5**: Demonstrate name mangling
