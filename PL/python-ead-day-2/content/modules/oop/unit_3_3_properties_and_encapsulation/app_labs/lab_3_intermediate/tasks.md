# Lab 3 Tasks: Computed Properties

## Task 1: Add Height and Weight Properties (20 points)
Add height (meters) and weight (kg) with validation.

## Task 2: BMI Computed Property (25 points)
Calculate BMI: weight / (height^2). Read-only.

## Task 3: Risk Level Property (30 points)
Compute risk based on vitals: NORMAL, WARNING, CRITICAL.

## Task 4: Status Indicator (15 points)
Return "Stable", "Monitoring", or "Alert" based on vitals.

## Task 5: Is Critical Property (10 points)
Boolean property: True if any vital in critical range.
