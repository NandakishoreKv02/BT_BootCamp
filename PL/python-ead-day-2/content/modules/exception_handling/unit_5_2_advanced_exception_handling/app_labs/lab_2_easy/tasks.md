# Lab 2 Tasks

## Task 1: The Wrapper
- Implement `calculate_with_logging(a, b, logs)`.
- Try `a / b`.
- If successful, return result.

## Task 2: Logging
- Except `ZeroDivisionError`.
- Append `"Zero Division Detected"` to `logs`.

## Task 3: Re-raising
- After logging, use `raise` to re-throw the exception.
- Do NOT return a fallback value or None. The function MUST fail.
